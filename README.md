# Gatherly Event Builder

A dependency-free event creation app for planning casual gatherings like a BBQ.

Open `index.html` in a browser to use it. Events are saved in local browser storage, and the app can track guests, food and drink preferences, budget, expenses, generated party bring suggestions, task assignments, CSV-backed grocery recommendations, copy invite text, and download an `.ics` calendar file.

For CSV-backed grocery recommendations, run the app from a local server so the browser can fetch `grocery_item_store_matching_seed.csv`.
